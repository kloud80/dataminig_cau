브라우저로 열고 `F` 를 누르면 전체화면입니다. 설치할 것은 없습니다.

## 구성 — 95슬라이드

| 구간 | 내용 | 쪽 |
|---|---|---|
| 1부 | 데이터 분석 기초 — 평균에서 다중회귀까지 | 1–53 |
| 전환 | statistics → heuristics | 54 |
| 2부 | 기계학습의 역사 — 기대와 겨울, 그리고 돌파 | 55–95 |

직접 눌러 보는 슬라이드가 두 장 있습니다. **60쪽**은 단층 퍼셉트론이 가중치를
고쳐 가는 과정, **83쪽**은 순전파부터 역전파·가중치 갱신까지를 한 단계씩
계산해 보여 줍니다. 표의 숫자는 모두 그 자리에서 계산된 값입니다.

## 이 저장소에 들어 있는 것

발표에 필요한 것만 있습니다 — `present.html` 과 그 페이지가 실제로 불러오는 파일들.

```
present.html   발표용 뷰어 (이 파일 하나만 열면 된다)
index.html     present.html 로 보내는 첫 페이지
_ds/           디자인시스템 — 폰트·색·타이포
uploads/       생성·가공한 이미지
assets/        원본 PPTX 에서 추출한 이미지
vendor/        차트 런타임 (React + 마운트 스크립트)
```

슬라이드 원본(`*.dc.html`)과 빌드·검증 스크립트는 저장소에 넣지 않았습니다.
목록은 `.dcpull/publish_files.py` 가 브라우저 요청을 그대로 기록해서 만들고,
`.gitignore` 가 그 목록을 허용 목록으로 씁니다.

## 웹 퍼블리싱 관련 주의

루트의 **`.nojekyll` 은 지우면 안 됩니다.** GitHub Pages 는 기본으로 Jekyll 을 돌리고,
Jekyll 은 `_` 로 시작하는 폴더를 무시합니다. 이 파일이 없으면 `_ds/` 가 통째로 404 가 되어
폰트와 색이 전부 사라집니다.

마찬가지로 **`vendor/` 가 빠지면 차트 27개가 조용히 사라집니다.** 그런 상태가 되면
슬라이드에 빨간 안내 상자가 뜨도록 해 두었습니다.
